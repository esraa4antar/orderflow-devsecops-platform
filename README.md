# OrderFlow DevSecOps Platform

A production-like cloud-native DevSecOps project built to demonstrate modern infrastructure, CI/CD, GitOps, security, Kubernetes and observability practices.

## Project Goal

Build and operate a full-stack application using modern DevOps practices from local development to a production-like AWS Kubernetes environment.

## Planned Stack

### Application
- React
- Django REST Framework
- PostgreSQL
- Nginx

### DevOps
- Docker
- Docker Compose
- GitHub Actions
- Terraform
- AWS
- Kubernetes
- Helm
- Argo CD

### DevSecOps
- Trivy
- Kubernetes security best practices

### Observability
- Prometheus
- Grafana
- OpenTelemetry
